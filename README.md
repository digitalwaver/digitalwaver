## 🏗️ How I Build Systems

I care about more than getting features to work.

I try to design systems around:

**Scalability** → services should handle growth without unnecessary complexity.

**Reliability** → failures should be observable, recoverable, and isolated.

**Maintainability** → future engineers should understand why the system was designed that way.

**Performance** → latency, database access, caching, and asynchronous processing matter.

**AI Evaluation** → LLM output should be tested and measured instead of treated as a black box.
